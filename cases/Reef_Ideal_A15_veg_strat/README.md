# Reef_Ideal_A15_veg_strat

Reef_Ideal_A15_veg with evolving temperature and salinity, a constant initial
stratification (N^2 = 1e-4 s^-2) and an open north boundary with nudged
radiation plus an interior nudging band. Application flag `REEF_IDEAL_A15`.
Other N^2: `tools/stratification/make_strat_init.py`. See
[docs/Reef_Ideal_A15_veg_strat.md](../../docs/Reef_Ideal_A15_veg_strat.md).
