# Circle_Island

A round island with a fringing reef on a closed log-polar O-grid, ROMS + SWAN.
Application flag `CIRCLE_ISLAND`. Every input file is written by
`make_case.py` (`python3 -I make_case.py [OUTDIR]`). Needs coawst-cloud's
`swan-periodic-curvilinear` and `swan-closed-ring`. See
[docs/Circle_Island.md](../../docs/Circle_Island.md).
