# Swan_Periodic_Test

Standalone SWAN test of periodic lateral boundaries (`COORDINATES CARTESIAN
REPEATING`) on regular and curvilinear reef grids. Application flag
`SWAN_PERIODIC_TEST`. Inputs: `make_inputs.py` and `make_curv_inputs.py`;
runs: `run_tests.sh`, `run_curv_tests.sh` (Docker); checks: `compare.py`,
`compare_curv.py`. See [docs/Swan_Periodic_Test.md](../../docs/Swan_Periodic_Test.md).
