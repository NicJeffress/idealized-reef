# Reef_Ideal_A15_veg

Reef_Ideal_A15 with a coral canopy (vegetation drag, canopy turbulence, SWAN
wave dissipation). Application flag `REEF_IDEAL_A15`. Plants are cylinders:
`plant_thickness = (pi/4) x plant_diameter`. Spatial canopy patterns:
`tools/vegetation/make_veg_init.py`. See
[docs/Reef_Ideal_A15_veg.md](../../docs/Reef_Ideal_A15_veg.md).
